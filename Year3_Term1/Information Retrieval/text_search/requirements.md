Based on the data crawled in Week 1 tutorial, students should construct a text-based search engine using the python library whoosh.

Whoosh tutorial can be found here: https://whoosh.readthedocs.io/en/latest/quickstart.html

The search engine needs to have an interface, implemented using a library such as streamlit. An example of a search engine interface built with streamlit.

Requirements:

Text-based searching using whoosh (5 pts).

A graphical user interface (GUI), showing the input (query) and output (matched documents) (4 pts).

The search engine should index the dataset only once (1pts).

Due to how streamlit works, the script will be re-run every time an interaction is made.

If handled improperly, the search engine will re-index the documents every time, causing a slowdown in speed and affecting user experience.

To get full marks, you should make sure that the dataset is indexed only once.

Students should work individually. Cheaters may face suspension if caught.

Submission requirements:

Students must put all of their source code into a folder named <MSSV></mssv> and zip them in a flie named <MSSV></mssv>.zip, where <MSSV></mssv> is replaced with the student’s ID (without the signs).

The source code MUST contain a requirements.txt denoting the python libraries needed to run the code. SUBMISSIONS THAT CANNOT BE RUN CAN BE MARKED 0.

The application to be run should be named “main.py”, “app.py”, or be mentioned in the README.
